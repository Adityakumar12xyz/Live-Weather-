**Live Weather Tracker** is a lightning-fast, high-performance web application engineered to deliver hyper-accurate, real-time weather updates. Designed with a mobile-first approach, it provides users with precise local forecasts, atmospheric data, and severe weather alerts in an incredibly intuitive interface.

---

## 🎨 UI/UX & Design Architecture

The application boasts a modern, distraction-free interface built for instant readability and visual appeal. 

*   **Dynamic Theme Adaptation:** The UI dynamically adjusts its color palette based on current weather conditions (e.g., sunny, rainy, thunderstorm).
*   **Glassmorphism UI:** Features sleek, frosted-glass panels with subtle blur effects for a premium look.
*   **Smooth Animations:** Fluid CSS3 transitions for data loading, hover states, and seamless page interactions.
*   **100% Responsive Layout:** Pixel-perfect grid architecture ensuring a flawless experience across all devices—from mobile screens to desktop monitors.

---

## ✨ Core Features

*   **📍 Auto-Geolocation:** Instantly detects the user's current location to provide immediate, area-specific weather data without manual entry.
*   **🌡️ Real-Time Metrics:** Displays accurate current temperature, "feels like" temperature, humidity levels, and wind speed.
*   **📅 Extended Forecasting:** Comprehensive 7-day weather predictions and detailed hourly breakdowns to help users plan ahead.
*   **🌫️ Air Quality Index (AQI):** Live monitoring of local air pollution levels to ensure health and safety.
*   **🚨 Weather Alerts:** Immediate warnings for severe weather conditions like heavy rain, storms, or extreme heat.
*   **🔍 Smart City Search:** Lightning-fast search functionality to check the weather in any city around the globe.
